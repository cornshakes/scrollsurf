# Scrollsurf

Scrollsurf lets you scroll through random wikipedia articles and like/dislike each of them.
You can view your liked/disliked articles and change your mind later if you want.
Next, I want to think about a way to make the random articles less random by using your liked/disliked articles in some way.


## Getting Started

```bash
npm install
```

```bash
npm run dev
```

[http://localhost:3000](http://localhost:3000)
